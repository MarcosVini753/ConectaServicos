Perguntas frequentes

Quer saber mais antes de começar?

Veja como funciona esta versão inicial da ConectaServiços.

O cadastro tem algum custo?

Não. O envio de solicitações e o cadastro de interesse profissional são gratuitos nesta demonstração.

A ConectaServiços já realiza atendimentos?

Ainda não. Este é um protótipo acadêmico que demonstra o fluxo de cadastro e recebimento de informações. Nenhum atendimento ou contato entre as partes é realizado.

O que acontece depois que eu envio?

Você verá uma confirmação. Os dados enviados são armazenados no serviço de formulários utilizado pelo projeto para fins de demonstração.

Como meus dados são utilizados?

Os registros servem para testar e apresentar o funcionamento do sistema. Evite utilizar informações reais ou sensíveis. Consulte nossa página de privacidade.
